☁ Sync across devices (optional)

Use the same private key (20+ characters, not your admin password) on each device. Changes are merged, never overwritten: favorites and settings follow the newest change, and launch counts add up across devices. Tick “Remember key” for automatic syncing, which stores the key in this browser.
